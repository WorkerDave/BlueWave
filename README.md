# Bluewave downloads

Official Windows builds of Bluewave. This repository contains release downloads and update metadata only. App and website source repositories remain private.

[Download the latest installer](https://github.com/WorkerDave/BlueWave-Downloads/releases/latest)

Install the Setup version once. It checks for updates and downloads them in the background. Choose **Restart to update** when you are ready; your library and music sign-ins stay on this device. Portable builds are manual updates.
